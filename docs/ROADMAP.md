# Bibliocrunch roadmap

## α 0.1 — deterministic folding prototype

- Complete 66-book KJV corpus
- Five fold schemas
- Six relation overlays
- Interactive 3D projection
- Geometry measurements
- Axis and neighborhood readings
- Seeded shuffle control
- Obsidian Markdown export

## α 0.2 — corpus profiles

- Define a versioned corpus-adapter format
- Import deuterocanonical and apocryphal books
- Switch among Protestant, Catholic, Orthodox, and custom book orders
- Preserve alternate Psalm numbering and verse mappings
- Export a complete experiment manifest with content hashes

## α 0.3 — original-language number systems

- Add a declared Hebrew source edition
- Add a declared Greek source edition
- Preserve lemmas, surface forms, and manuscript variants separately
- Implement selectable Hebrew gematria and Greek isopsephy functions
- Never label English A1Z26 as Hebrew or Greek gematria

## α 0.4 — geometry search

- Generate a typed numeric-relation graph and hypergraph
- Fit Euclidean, spherical, toroidal, and hyperbolic candidate spaces
- Score embeddings by stress, symmetry, sparsity, and description length
- Detect collinear sets, planes, cycles, shells, convex-hull vertices, and symmetry orbits
- Produce reproducible reading paths from discovered structures

## α 0.5 — serious controls

- Run matched permutation ensembles rather than a single shuffle
- Report empirical null distributions and effect sizes
- Correct for multiple folds, feature sets, and path searches
- Compare results across canon and versification profiles
- Store interpretations separately from computed observations

## 1.0 — fold laboratory

- Save and share versioned experiment manifests
- Compare two folds or canons side by side
- Export graph layers and verse notes directly into Obsidian vaults
- Publish a documented plugin API for new folds, relations, corpora, and numeric systems
